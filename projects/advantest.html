Context

Advantest is a global leader in semiconductor test equipment. Their SmarTest8 platform powers validation workflows on the V93000 tester architecture — a complex domain with specialized syntax, hardware specification documents, and strict compliance requirements.

Engineers routinely spent significant time writing and integrating firmware scripts and retrieving hardware specifications from dense technical documentation. My internship focused on applying modern LLM techniques to accelerate these workflows while maintaining accuracy and adherence to validation standards.

Problem

Three bottlenecks defined the engineering workflow:

  • Domain-specific code generation

    General-purpose LLMs hallucinated SmarTest8 syntax and produced scripts incompatible with the V93000 architecture.

  • Specification retrieval

    Hardware specs lived across lengthy, unstructured documents — manual lookup was slow and error-prone.

  • Production inference constraints

    Multiple engineers needed concurrent access to large models without saturating GPU resources or degrading latency.

Key Contributions

  • Domain fine-tuning with QLoRA

    Fine-tuned Llama 3.3 70B on SmarTest8 syntax using QLoRA, starting from a 4 GB proof-of-concept and scaling to 48 GB VRAM after demonstrating high-impact results to the team.

  • RAG pipeline for specification retrieval

    Engineered a retrieval-augmented generation pipeline using BAAI/bge-m3 embeddings to ground model outputs in actual hardware documentation — eliminating hallucinations and accelerating spec lookup.

  • Production inference service

    Deployed a local FastAPI web service with a custom request queue to manage concurrent inference requests and optimize model throughput across multiple engineers.

  • Firmware integration automation

    Built LLM-driven scripts that automated firmware integration workflows, reducing engineering turnaround from approximately one week to five hours.

  • Validation standards documentation

    Synthesized technical documentation for semiconductor validation standards, ensuring AI-generated automation adhered to V93000/SmarTest8 architecture requirements.

Takeaways

This internship taught me how to take LLM research techniques — fine-tuning, RAG, quantization — and ship them as production systems that real engineers depend on daily. The biggest lesson was balancing model capability with infrastructure constraints: a working 4 GB proof-of-concept earned the trust to scale to a full 70B deployment.

Working under confidentiality also reinforced how to communicate technical impact clearly without exposing proprietary details — a skill directly applicable to any industry ML role.
