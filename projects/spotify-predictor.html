Problem

Spotify's popularity score (0–100) reflects how often a track is streamed relative to other songs — but what makes a song popular? Can audio characteristics alone predict success before a track is released?

This project explores that question by building regression models that predict track popularity from measurable audio features — danceability, energy, tempo, genre, and more — without relying on artist name or marketing data.

Features

The model uses 15 inputs drawn from Spotify's audio analysis API:

Category Features
Audio danceability, energy, loudness, speechiness, acousticness, instrumentalness, liveness, valence, tempo
Metadata duration (ms), explicit, key, mode, time signature
Categorical track genre (one-hot encoded)

Models Compared

Model Test R² Notes
Linear Regression ~0.60 5-fold cross-validation baseline
Decision Tree ~0.56 Bayesian hyperparameter search
Random Forest ~0.59 Bayesian optimization (1-hour run)
Bagging Regressor ~0.69 Strong fit with some overfitting
LightGBM ~0.70 Bayesian-tuned gradient boosting
XGBoost ~0.70 Best overall — selected for deployment
Neural Network ~0.63 TensorFlow/Keras dense layers

Tree-based ensemble methods significantly outperformed linear regression, with XGBoost and LightGBM reaching ~0.70 test R². Bayesian optimization via scikit-optimize was used to tune hyperparameters for the top candidates.

Exploratory Data Analysis

  • Popularity distribution

    Analyzed track popularity histograms, filtering zero-popularity tracks and handling missing values across ~91K records.

  • Feature distributions & outliers

    Box plots and distribution charts for all 14 numerical audio features to identify skew and outliers.

  • Release date enrichment

    Built a custom scraper notebook to merge release dates onto tracks for temporal analysis.

  • Residual analysis

    Residual vs. predicted plots, Q-Q plots, and per-genre error breakdowns to validate model assumptions.

Deployment

The final XGBoost model was deployed as an interactive Hugging Face Space where users can input audio features and get a predicted popularity score. A demo video walks through the full workflow from data to prediction.
